# ChatakBatak

# How to run ChatakBatak
## 1. Clone the Project Reporsitory
    ```
    git clone https://github.com/SwarupDoesDSA/ChatakBatak.git
    ```

## 2. Navigate to  the Project Directory
    ```bash
    cd ChatakBatak
    ```

## 3. Create a Virtual Environment (optional but recommended):
    ```bash
    conda create -n chatakbatak python=3.14 -y
    ```

## 4. Activate the Virtual Environment:
    ```bash
    conda activate chatakbatak
    ```

## 5. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## 6. Run the Application
    ```bash
    python app.py
    ```
